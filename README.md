# Sheep Boss (Fabric 1.21.1)

## Сборка JAR
Нужны JDK 21 и Gradle 8.8+:

    gradle build

Готовый мод: build/libs/sheepboss-1.0.0.jar (НЕ -sources). Кладётся в mods/ вместе с Fabric API.

Без ПК: залей папку в репозиторий на GitHub — Actions (.github/workflows/build.yml) соберёт JAR,
скачать его можно во вкладке Actions -> artifact "sheepboss-jar".

## Как играть
* Крест из 5 блоков шерсти (любого цвета, лёжа или стоя), ПКМ красным факелом по центральному блоку -> босс.
* Босс: боссбар, x3 размер, красные лазеры с зарядкой глаз, каждые 60 секунд вызывает 30 пикирующих овец. На предупреждение «ОВЦА-СНАРЯД» нажми Shift, чтобы уклониться.
* При 50% здоровья босс переходит во вторую, роботизированную фазу с электрическими эффектами.
* С босса падает Овцебазука + 32 чёрной шерсти. ПКМ — быстрый выстрел взрывной овцой (1 чёрная шерсть), взрывается при столкновении с блоком или существом. У взрывной овцы собственная текстура.
* Тест: /summon sheepboss:boss_sheep или яйцо призыва. Играть в выживании — в креативе мобы не атакуют.
